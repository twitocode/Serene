# Serene

A mental health platform for university and college students.

## Features
- Checkin system for users to share how they are feeling at the moment; also includes a physical sensations section.
- Community page that currently includes a *Question of the Day* system for community engagement.
- Explore page that recommends mental health related content based on user age, gender, and struggles. 
  
## Features not added yet
- Trends page that shows users emotions over time
- Search for checkins and Question of the Day responses

## Tech Stack

Frontend
- Next.js frontend
- Tanstack Query
- Hosting on Vercel

Backend
- C# with ASP.NET Core
- EntityFrameworkCore with PostgreSQL
- Hosted on Railway
